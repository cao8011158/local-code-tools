# B4-REL-01: bounded relative `from` imports

Only `lct/simple_python.py` and `lct/python_incremental.py` production code changed. Strict and common syntax checks now ask the existing `Graph.import_request_module` for the importing module's canonical request before `Graph.imported` checks its actual unique captured provider, selected path, AST and exact exports. The dataclass external boundary remains restricted to absolute `from dataclasses import dataclass`; the strict `re` import is unchanged. `component_policy` joins importer/provider using that same canonical request. During local preparation, each changed/selected top-level `ImportFrom` canonicalizes once and enqueues the new target plus package context, including parent-level imports. Unsupported shapes, a missing/excluded target, and invalid relative levels still fail closed. The v6 certificate value is unchanged because previously accepted forms have the same meaning and the program hash rejects incompatible old build code.

Before implementation, `tests/test_relative_python_incremental.py` recorded **3 failed, 5 passed**: relative `.b` could not certify the predecessor at 0/20 unrelated modules, and a caller changing to a new `.c` provider fell back. Log: `relative-import-prechange.log`. After implementation, **12 passed** in `relative-import-focused.log` and **69 passed** across relative/common/cross-repository/dictionary/dependency/query-reuse cases in `relative-import-related.log`. The tests compare catalog nodes/edges and private sites, observations, import requests/dependencies and value evidence with an independently built fresh full graph. The 0/20 cases count exactly two parsed modules when the provider changes, while unrelated Python is reused. Parent-level `..b`, aliasing, same-named other package isolation, new provider import, failed publication/old view and incompatible old certificate were checked. `from . import b`, star, beyond-root, missing provider, captured `.dataclasses` impersonation and relative dictionary registry flow remain uncertified.

The six additional real fixed state-machine files from `actual-related-admission-audit.md` remain outside the closed grammar; this change normalizes import identity only and makes no claim of admitting the nine-file business capture. No business code was executed and no Graph/Jedi/schema/value-flow logic changed.

After production freeze, the one requested fast suite passed: **615 passed, 27 skipped** in `relative-import-fast-suite.log`. The independent reviewer test remains parent-owned and was not edited or included in these counts.

## Changes and actual behavior

`lct/value_flow.py` proves a narrow captured source shape: exact local literal dictionaries with string keys and callable definition values; straight-line module writes; exact same-repository imports; direct module/function aliases; and known-key subscript call sites. The full Analyzer still resolves targets and uncertainty. The internal model is emitted only when its actual subscript witness and public site agree with the source support, including an empty target set for a missing key. Unsupported sources retain full analysis. Numeric keys (`True`, `1`, `1.0`) are rejected by this certificate rather than split into inconsistent typed entries. Calls taking the registry, returns/escapes, dynamic keys, arbitrary module calls, conditional writes, loops, unsupported imports and rebinding do not gain local admission.

The private immutable SQLite `graph-sites.sqlite` sidecar stores version-scoped logical container, entry, source binding, write and read nodes, and indexed edges. `BINDS` records the provider declaration/import/alias to the same container; `USES_BINDING` links a read to the source binding. `ADDRESSES` denotes a storage position, with `present=false` for a missing key subscription; it does not assert runtime membership. `WRITES`, `VALUE`, `REACHES`, `READS` and `POSSIBLE_CALLS` show actual supported source and candidate function definitions. No semantic node enters the searchable catalog, vector levels or Neo4j projection. The manifest has schema/coverage/count/projection summaries, not the record lists. `FileDependencies` validates table/index/column/count metadata; `entry_ids_for_file` and `value_readers(entry_id)` use indexes. Bounded node and relation helpers return at most 100 requested nodes/relations; relation output reports `has_more`, never silently asserting completeness. Partial/budget evidence rejects impact queries.

`simple-python-v5` retains the v4 subset and admits only the new closed dictionary shape. `python_incremental.prepare` consumes old exact entry subscribers, module analysis readers and the capture-wide writer watchers (one watch query per preparation) in addition to file/import adjacency. Broad analyzer watch fanout is deliberately retained. Old/missing/partial evidence, missing analyzer witness or over-budget records causes full fallback. Selected semantic records are rebuilt; unchanged producer-only records use stable logical IDs and verified frozen source, and any read-site identity retained across capture would be rebound through the existing site map. Identical-capture reuse copies the sidecar records. Old published snapshots are not mutated, and failed candidate publication retains the prior pointer.

## Limits

This is a certified slice, not general Python value-flow precision. The private internal model does not project to Neo4j or MCP; public `CALLS` and unknown/boundary relations remain the existing projection. Branches, callbacks, default/closure cells, bound methods, arbitrary field and dictionary effects remain under the existing full analyzer and conservative fallback. This report does not claim runtime invocation counts or whole-project incremental locality.
The mixed certificate currently rejects a plain v4 module importing a function from a modeled dictionary module rather than certifying general transitive callers; this is an intentional full fallback. The record budget bounds persisted semantic evidence, while full initial analysis and immutable output maintenance can still scale with the captured inventory.

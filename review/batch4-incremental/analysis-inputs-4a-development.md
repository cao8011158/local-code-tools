# Batch 4A: shared analysis input purposes

Starting from `f7ecf028309c64a21e7e5493a51151e777aacba0`, this batch extends the existing private `AnalysisInputs` ledger, rather than adding a parallel record model. The old-code behavioral regression `test_non_jedi_entrypoints_share_one_scope_and_purpose_mask` failed because direct candidate, lexical, member and constant resolve calls left `consumers=[]` (log `analysis-inputs-4a-prechange.log`). The implementation adds schema 2 and `captured-analysis-scopes-partial`, keeping the same three tables and the 20,000 scope+member+consumer budget. Consumer rows OR five fixed purpose bits: Jedi 1, call candidates 2, lexical 4, member 8 and resolve 16. Additional purposes cost no row; repeat observations use the validated component cache and do not enumerate its members.

Analyzer's shared `_observe_analysis_input` maps scope identities to module owners and uses an existing validated component only while its site inventory remains intact. Unknown/out-of-component inputs use the capture scope. It runs before cache/early-return paths and refuses registration during `__init__` metadata preparation (an unexpected attempted observation raises rather than silently disappearing). `query` retains its original result/raw/Jedi policy; the other hooks do not change return values, effects or call graph. `Graph.build` already exports the ledger after value flow, with no new public node or graph field.

| Purpose | Hook and covered input decision | Remaining limit |
| --- | --- | --- |
| Jedi query (1) | `query` before in-memory/reusable cache, result, empty result or error | Jedi internal/external reads are not enumerated. |
| Call candidates (2) | `candidate_sites` and `sites_for` before empty/fallback return; `may_call` records the function consumer and actual site owner, broadening to capture when outside a proven component | No exact future-caller negative membership or arbitrary callback proof. |
| Lexical (4) | `name` and `reaching` before their searches/early returns, including absent names; stack owner maps nested lookup back to evaluating consumer | No per-name future binder subscription; `named_bindings` is reached through `reaching`, direct `named_bindings` is not separately instrumented. |
| Member (8) | `attribute` and `member` before lookup/absence, inherited-owner recursion through `member` | Unknown receiver/descriptor or future member is still conservative range evidence, not a complete semantic witness. `ReceiverAccess` paths that call these hooks are covered there; paths bypassing them are unproven. |
| Resolve (16) | `resolve` before missing value, memo hit, recursive/budget return and normal expression | A scoped input range does not replace the process-local expression dependency trace. Other direct effect/field logic remains governed by older partial evidence and v6 gate. |

SQLite consumer rows now store a typed positive known-bit mask. `FileDependencies` validates columns, endpoint ownership, exact component membership, row counts, orphan rows and mask, and reads actual schema 1 consumer columns by normalizing them to Jedi bit 1. The new build writes only schema 2. `prepare` and identical-capture reuse require schema 2/new coverage and otherwise rebuild safely. Local merging replaces selected consumers and retains the unchanged consumer's exact prior mask; no purpose is manufactured. Indexed reverse readers and capture watchers still select actual candidates, but partial scope coverage alone does not authorize unsupported Python. Manifest/status retain only schema, partial coverage, counts and truncation.

Focused tests cover the old behavior counterexample, zero/absent/member/cross-scope observations, OR/dedup/budget, guard against member re-enumeration, real schema 1 columns, invalid masks, local/full private ledger equality, failed publication old view, identical capture, and missing/truncated/unknown evidence. The unrelated 0/20 oracle uses the existing exact three-file fixture. No six-file complex business capture was admitted. This batch did not loosen `simple-python-v6`, modify Jedi/EffectCatalog, or claim complete read proof.

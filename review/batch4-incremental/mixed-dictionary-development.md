## Cause and change

After `capture_shape` had validated the modeled dictionary modules A/B, `certify` passed only ordinary `plain_files` to `_certify_v4`. That helper defined its import universe from its own input files, so C's ordinary `from b import run` failed solely because B was omitted from `plain_files`, even though B's captured AST was present and its dictionary shape had been validated. The prior independent baseline (`mixed-dictionary-baseline-independent.log`) had three update failures and three passing conservative controls: changes selected unrelated files through full fallback.

`_certify_v4` now has a **private optional** `selected_context`. Its default remains the original self-contained file set. Only after the mixed dictionary shape succeeds does `certify` pass the complete `(repository,path)` set of supplied captured Python files as context while validating only the plain files' bodies. For each ordinary import, the original checks still require the exact `Graph.imported` target, one captured module in that context, its actual AST, and the directly exported FunctionDef/ClassDef name. Unsupported syntax, missing modules/exports/AST, ambiguous names and pin boundaries continue to fail. No parser, analyzer, semantic model, SQLite schema, Neo4j or embedding behavior changed.

The selected update component can now include A's literal dictionary/write, B's known-key read, C's ordinary caller and D's caller of C. The existing adjacency/import and value-flow reverse indexes select them; this change does not add a new reverse index or imply arbitrary dynamic callers. Root's independent 0/20-noise controls parse only A/B/C on a target change and deletion, or A/B/C/D for a new formerly absent key, while retaining an unrelated producer-only dictionary. Local and fresh full outputs agree for catalog nodes/edges, sites, imports, query observations and value-flow tables; failed publication keeps the prior version. The new own tests also cover absent target AST, missing export, provider rebind, dynamic key, conditional write and registry escape fallback.

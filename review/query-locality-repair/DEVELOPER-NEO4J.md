All cursors are stateless within the fixed HTTP namespace/version and must be reused with the same kind/repository filters, ID list, relation types and direction; they are not interchangeable across queries. Since completed scopes are immutable by import contract, normal continuation is stable. A single record beyond the budget produces a clear error on its page, not silent omission; preceding records can be returned on a prior page. An explicit full `snapshot_info` still reads all chunks for offline inspection; normal status never invokes it. Marker query itself validates complete scope on every request. The new identity fields are derived during import and belong to that immutable marker; failed import remains hidden.

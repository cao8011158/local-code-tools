# Snapshot metadata locality

Each new version publishes `summary.json` after full artifact validation. Ordinary Query calls read that small file and check required artifact membership, regular-file sizes, and SQLite sidecars once per Query/version. Full checksums, SQLite integrity, and catalog count checks remain required at build publication, explicit recover, and portable backup/restore. The original `manifest.json` remains in the version and is never read by ordinary queries.

The summary preserves version, schema, format, program/config hashes, repository revisions, source fingerprint, partition descriptors, counts, and graph analysis totals. Complete source-file inventory is in checksummed `source-files.json`; complete ordered graph sites and unresolved reasons are in checksummed `graph-sites.sqlite`, indexed by ordinal. `storage.source_files(folder,m)` and `storage.graph_detail(folder,m)` reconstruct the original full objects for an explicit import. `Query.graph_evidence(offset,limit,max_bytes,version)` and MCP/CLI `graph_evidence` page sites by ordinal, returning `next_offset` and `total`. A single oversized site raises an explicit error; no evidence is silently dropped. `index_status` reports graph totals and directs the caller to the detail tool.

Existing versions require explicit offline `migrate-metadata --version VERSION --expected-program-hash OLD_HASH`. It verifies the old complete manifest, exact old program hash, current config/model/schema/format, all frozen artifacts and SQLite integrity; it writes sidecar evidence and publishes `summary.json` last. The old manifest bytes and version ID remain unchanged, so retained cursor bindings keep their identity. Interrupted preparation can be retried; no current pointer changes. A complete unmigrated version fails ordinary queries with a migration instruction and prevents backup from silently dropping it. Migrate each retained complete version before backup. Restore verifies both original and summary/evidence, then rebinds compatible summaries and only new-format original manifests to the relocated config.

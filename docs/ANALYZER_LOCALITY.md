# Analyzer locality in Batch 3

`Analyzer.parameter` and `registry_arguments` retain the existing `may_call` gate and exact `resolve` target checks. A per-analysis index only skips call sites when an **already cached** Jedi observation proves that they cannot pass `may_call` for the requested function. The index is built from the existing `self.sites` order and the same query key `(module, end_lineno, end_col_offset, False)`; it never makes an eager Jedi request.

For a given function, candidate sites are the sorted union of syntactically matching callee spellings, cached observations with an atom for that exact target node ID, cached observations with no atoms (including failures), and all sites not yet observed. These are precisely the cases `may_call` admits or still needs to inspect. `may_call` runs again on every candidate, followed by the original exact resolution and argument/receiver logic. A query in progress or a changed site count falls back to the old full scan. The class-construction receiver fallback has a different predicate and is deliberately unchanged. An alias, rebound attribute, callback, or unknown call is never excluded by spelling alone. The index changes neither the analyzer's recursion budget nor site ordering, raw Jedi evidence, or UNKNOWN handling.

`map_name` also indexes captured definitions by `(module, definition_line)` once. Its exact token/column/type checks are unchanged; if tests or callers alter the node/module maps after construction, it falls back to the original scan. Source lines are split once per captured module and reused by `map_name` and `query`.

This optimization reduces repeated warm-site scans and repeated all-node definition lookups. Cold sites still require their existing Jedi observations, and an early parameter resolution may still visit many unqueried sites. It is not a guarantee that the business build meets a particular elapsed-time or memory target. The local acceptance test checks cold/warm predicate equivalence, alias and attribute admission, unknown/error admission, reentrant fallback, and a 300-site warm negative set; existing semantic regressions check target and UNKNOWN outputs. A complete captured-source build should be separately measured before a scale claim.
